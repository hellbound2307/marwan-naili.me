Research pillars

Agentic systems

Platforms where a model calls tools, runs unattended, and can break its own environment. I work on the parts that only fail under real load: sandbox containment, loop detection, tool-allowlist design, graceful degradation when a model returns nothing, and the CI needed to ship a fork for years without drift.

Android · Linux · Python · CI/CD · capability security

Applied ML & evaluation

Retrieval systems that know when they don't know, and evaluations that aren't lying to me. Supervised fine-tuning on constrained hardware, routing between small specialist models, adversarial needle-retrieval, and the unglamorous work of building a gold set so a benchmark means something.

RAG · abstention · SFT · routing · adversarial evals

Security measurement

Exposure enumeration, malware and exfiltration analysis, and attack-surface review of real applications. Non-intrusive by default: passive indexes, protocol identification, static and dynamic analysis on samples I already hold. No exploitation, no credential testing, no state-affecting action.

Exposure · RE · OSINT · appsec · coordinated disclosure

Systems I build

Minis X

A full agent platform: on-device model routing, tool execution, a Linux sandbox for untrusted code, plugin/MCP extension with a declared-permission model and a network allowlist, scheduled tasks, a persistent encrypted vault, and run telemetry. Ships through CI as a signed Android build, verified on-device after every release.

Agents · Android · capability sandbox · CI releases

ARGUS — evidence-grounded identity resolution

An entity-intelligence system that runs entirely from a phone: no cloud, no rented compute. Content-addressed raw evidence in SQLite, a resolver that returns SAME / DIFFERENT / UNKNOWN with its evidence attached, per-source coverage states so "we didn't check" never looks like "nothing found", and report generation with a citation validator that fails closed.

OSINT · entity resolution · provenance · citation validation

PANOPTES — observation layer

A cron-snapshot geospatial feed on edge workers: earthquakes, military and civilian flights, satellites, fires, hazards and news, collected on schedule and normalised into a historical store. Deliberately inverted from per-request fan-out — the observation is the record, not a query. Includes an Algeria-scoped variant.

Edge workers · data pipelines · historical observation store

CyberRAG

A retrieval arsenal over WSTG, ATT&CK, exploitation references and my own field notes, rebuilt around a single rule: it is allowed to abstain. Concept queries and CVE lookups are separate indexes so the catalogue can't poison the corpus, and an unseen query term is treated as proof the corpus lacks the topic.

Retrieval · IDF weighting · calibration · eval harness

Wormlab

An open research question I could not find answered: what is the actual capability floor of small open-weight models used as autonomous cyber tooling? Existing claims test one hidden model size and call it a result. I am building the sweep — size versus fitness, micro-policies versus language models, payload execution versus rhetoric — with a publication plan attached.

Research · literature review · experimental design

DarkTortilla RAT — exfiltration channel analysis

Reverse engineering of a commodity Android RAT's Telegram-based exfiltration path: payload extraction, protocol reconstruction from recovered code, and derived indicators of compromise.

Reverse engineering · threat analysis · public

Algeria wilayas & communes dataset

All 69 wilayas and their communes, updated for the 2026 administrative reform, with bilingual naming and a documented generation procedure so the build is reproducible rather than a one-off export.

Dataset · reproducible build · public

How I work

  • Verify the targetA flag, a test run, or a passing command proves the mechanism worked. It never proves the objective did. I check the actual state, every time.
  • Preserve what worksSmallest change that satisfies the requirement. Incremental beats elegant. I would rather ship a rough system that runs than a clean one that does not.
  • Say what I don't knowObserved, reported, inferred and unknown are kept apart. A subagent's claim is evidence to check, not evidence.
  • Publish the methodMethod, timestamp, source and repro steps travel with the finding. Otherwise it is a claim with a screenshot attached.
